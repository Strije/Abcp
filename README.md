# Автодруг — мобильное приложение магазина автозапчастей

Android-приложение для покупателей [avtodrug92.ru](https://avtodrug92.ru) (Севастополь):
поиск запчастей и заказ через платформу **ABCP**, подбор по автомобилю через **Laximo**.

## Что умеет

- **Поиск по артикулу**: бренды → «Искомый номер» и «Аналоги», сортировка «Быстрее / Дешевле»,
  фильтры «Сегодня» / «До 3 дней», метки поставщиков, вероятность поставки, «Показать все варианты»,
  «С этим товаром покупают», поиск фото в Яндексе/Google. Без входа — с ценами гостевого профиля.
- **Подбор по авто**: VIN, номер кузова, госномер (в том числе с фото — распознавание на телефоне),
  схемы узлов Laximo → OEM-номер → цены.
- **Корзина и заказ**: все корзины (мультикорзина), количество с учётом кратности, оплата,
  самовывоз/доставка, офис, дата отгрузки.
- **Заказы**: активные/завершённые, статусы позиций, отмена позиции, оплата долга онлайн,
  уведомления о смене статуса и их лента.
- **Главная**: новости и акции (страницы сайта `news1…news4`), баланс и пополнение, магазины, чат с менеджером (Битрикс24).
- **Гараж**, регистрация, восстановление пароля.

## Устройство

| Папка | Что там |
|---|---|
| `app/` | Приложение: Kotlin, Jetpack Compose, Retrofit/OkHttp, WorkManager, ML Kit |
| `app/src/main/java/.../abcp/` | Клиентский API ABCP: поиск, корзина, заказы, уведомления |
| `app/src/main/java/.../laximo/` | Каталоги Laximo: подбор авто, схемы |
| `app/src/main/java/.../server/` | Обращения к нашему серверу |
| `server/` | Сервер (Python, FastAPI): то, что ABCP даёт только API-администратору — баланс, оплата, гостевой поиск, регистрация. См. [server/README.md](server/README.md) |

## Сборка

Сборку делает GitHub Actions при каждом push (`.github/workflows/android.yml`), APK — в разделе Artifacts.
Нужные секреты репозитория: `LAXIMO_USER`, `LAXIMO_PASS`, `DEBUG_KEYSTORE_B64` (постоянный ключ подписи,
чтобы новые версии вставали поверх).

Локально (Android Studio) — в `local.properties`:

```
LAXIMO_USER=...
LAXIMO_PASS=...
# необязательно, по умолчанию тестовый сервер
SERVER_URL=https://...
```

## Важно про лимиты ABCP

На тарифе магазина `articles/info` (картинки, кроссы) — 10 запросов в сутки, `search/tips` — 100 в сутки,
поэтому они не используются. Основной поиск (`search/brands`, `search/articles`) — сотни тысяч и миллионы в сутки.
