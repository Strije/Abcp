# Автодруг92 — приложение магазина автозапчастей

Android-приложение для покупателей [avtodrug92.ru](https://avtodrug92.ru) (Севастополь) и сервер к нему.
Магазин работает на платформе **ABCP**, подбор по автомобилю — каталоги **Laximo**.
Опубликовано в RuStore («Автодруг92 — автозапчасти Севастополь»), есть и прямая раздача APK с автообновлением.

План работ — [docs/ROADMAP.md](docs/ROADMAP.md). Правила для работы с кодом — [CLAUDE.md](CLAUDE.md).

## Что умеет приложение

**Поиск и выдача**
- Одно поле на главной: артикул, VIN, номер кузова или госномер — приложение само понимает, что введено.
- Фото вместо ввода (распознавание на телефоне, ML Kit): табличка VIN, СТС, госномер, штрихкод или надпись на упаковке.
- Выдача как на сайте: «Вы искали» закреплено сверху, ниже аналоги; карточка артикула с фото, предложения
  цветными плашками поставщиков со значками сайта (Font Awesome), «Показать ещё N», «Показать все варианты».
- Сортировка «Быстрее / Дешевле», фильтры «Сегодня», «До 3 дней», «🛡 С гарантией», «★ Частые замены».
- ★ «Частая замена» — аналог предлагают 2+ поставщика; по нажатию — объяснение и «Спросить менеджера».
- Гарантия избранных брендов: оранжевая плашка со сроком, рейтинг кубками 🏆, условия по нажатию.
- Номер в карточке — новый поиск по нему; «С этим товаром покупают»; фото в Яндексе/Google.
- Без входа — поиск с ценами гостевого профиля.

**Подбор по автомобилю** — VIN, кузов, госномер → каталог Laximo → схема узла с выбором детали → OEM-номер → цены.
«Моя машина» на главной (избранная из гаража) — фильтры, тормоза, подвеска… в одно касание.

**Корзина и заказ** — все корзины ABCP, количество с учётом кратности, самовывоз/доставка, офис, дата;
предупреждение, если цена или наличие изменились. После первого заказа — одна просьба снять ограничения батареи,
чтобы уведомления приходили сразу.

**Заказы** — активные и завершённые, статусы позиций, отказ от позиции (пока «Ожидает обработки»),
оплата долга онлайн, «Повторить заказ» с сегодняшними ценами, «Купить ещё», переход к ценам по номеру.

**Уведомления (push RuStore)** — смена статуса позиции; «Готово к выдаче» с адресом и маршрутом,
«Ждёт оплаты», «Задерживается»; рассылки и адресные сообщения из Telegram-бота; ответ менеджера в чате.
Лента уведомлений в приложении. Без push — проверка статусов из приложения раз в 20 минут.

**Ещё** — баланс и пополнение, новости и акции с сайта, магазины с «Позвонить» и «Маршрут», гараж,
чат с менеджером (Битрикс24, клиент и его ID сразу видны оператору в CRM), регистрация и восстановление
пароля, заявка на включение доступа к API (если менеджер ещё не включил права), приветствие из 4 экранов
и разовые подсказки, AppMetrica (события и ошибки).

## Устройство

| Папка | Что там |
|---|---|
| `app/` | Android: Kotlin, Jetpack Compose, Retrofit/OkHttp, WorkManager, ML Kit, Coil |
| `app/…/abcp/` | Клиентский API ABCP: поиск, выдача, корзина, заказы, гарантии, уведомления о статусах |
| `app/…/laximo/` | Подбор по авто и схемы (запросы идут через наш сервер) |
| `app/…/server/` | Обращения к нашему серверу, автообновление |
| `app/…/push/` | Push RuStore, просьба про батарею |
| `server/` | Сервер (Python, FastAPI) — см. [server/README.md](server/README.md) |
| `docs/` | План работ, политика конфиденциальности (опубликована на avtodrug92.ru/data_protection) |

Зачем сервер: часть ABCP доступна только API-администратору (баланс, оплата, регистрация, гостевой поиск,
картинки), а его пароль нельзя класть в приложение. Там же пароль Laximo, push, бот и чат с Битрикс24.
**В приложении нет ни одного пароля или ключа доступа.**

## Две версии

| Версия | Для чего | Обновления |
|---|---|---|
| `rustore` | Публикация в RuStore | Через RuStore (RuStore Update SDK), там же оценка приложения |
| `direct` | Раздача APK напрямую | Своё автообновление с нашего сервера |

## Сборка

Android Studio не нужна — собирает GitHub Actions на каждый push (`.github/workflows/android.yml`),
APK обеих версий — в Artifacts. Номер сборки = номер запуска CI (`1.0.N`).

- Подпись — release-ключ из секретов `RELEASE_KEYSTORE_B64`, `RELEASE_KEYSTORE_PASS`
  (отпечаток SHA-256 `4A:7F:45:28…D6:97`). Сменить ключ = приложение нельзя будет обновить поверх.
- Сборку `direct` из `main` с этим ключом CI сам выкладывает на сервер обновлений (секрет `APP_UPLOAD_TOKEN`).
- Ошибки компиляции видны в аннотациях: `api.github.com/repos/Strije/Abcp/check-runs/{job}/annotations`.
- Тесты сервера — `.github/workflows/server.yml`; проверка сервера снаружи раз в 15 минут — `uptime.yml`.
- Сжатие R8 пока выключено (сборка 1.0.60 с ним падала).

Для локальной сборки другой адрес сервера можно указать в `local.properties`: `SERVER_URL=https://...`

## Ограничения ABCP

- `articles/info` (картинки) — 10 запросов в сутки на тарифе магазина, сервер расходует их бережно и кэширует.
- `search/tips` — 100 в сутки, не используется.
- Права на API существующим клиентам менеджер включает вручную в карточке клиента (ошибка 103 = нет прав);
  новым клиентам, зарегистрированным из приложения, права ставятся сами.
