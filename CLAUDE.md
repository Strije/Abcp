# Автодруг92 — приложение и сервер

Приложение магазина автозапчастей Автодруг92 (Севастополь) на платформе ABCP + подбор Laximo.
План работ — [docs/ROADMAP.md](docs/ROADMAP.md). Отвечать пользователю по-русски, простыми словами.

## Как устроено

- `app/` — Android (Kotlin, Compose). Две версии: `rustore` (в RuStore, без своего автообновления)
  и `direct` (раздача напрямую, автообновление с нашего сервера). Пакет `ru.avtodrug92.app`.
- `server/` — FastAPI: всё, что ABCP даёт только API-администратору (баланс, оплата, регистрация,
  гостевой поиск), прокси Laximo, push RuStore, заявки на доступ и бот @av92_bot. См. `server/README.md`.
- Секретов в репозитории НЕТ и быть не должно (он публичный): пароли и токены — только
  в `/etc/avtodrug-api.env` на сервере и в секретах GitHub.

## Сборка и выкладка

- Android Studio / SDK на рабочем ПК нет — собирает GitHub Actions на каждый push в `main`.
  Ошибки компиляции — в аннотациях: `api.github.com/repos/Strije/Abcp/check-runs/{job}/annotations`.
- Сборка `direct` из `main` с release-ключом сама уходит на сервер обновлений.
- Сервер: тестовый VPS 194.87.208.68 (на нём же VPN пользователя — **перед и после любых изменений
  проверять VPN-подписку**, она важнее всего). Код сервиса — `/opt/avtodrug-api`, служба `avtodrug-api`.
- Тесты сервера: `cd server && python -m pytest -q`.

## Правила

- Закупочные цены (priceIn) и персональные данные клиентов никогда не отдавать наружу и не писать в логи.
- Лимиты тарифа ABCP: `articles/info` — 10 в сутки, `search/tips` — 100 в сутки (не использовать).
- Коммиты — по-русски, по одному смысловому изменению.
