# План работ — приложение «Автодруг» (обновлён 25.09.2026)

## Ждёт пользователя

- **Крупный шрифт**: проверить сборку на телефоне с увеличенным шрифтом (Настройки → Экран), прислать
  скриншоты мест, где текст обрезается (плитки главной, плашки выдачи, кнопки).
- **Задержка push**: проверить с «Без ограничений» батареи для «Автодруга» (и RuStore) — приходят ли сразу.
- **Чат через свой канал Битрикс24**: разрешить на MikroTik (bitrix.freno.ru) вход с 194.87.208.68,
  затем «Переустановить» локальное приложение в Битрикс24 и включить канал в открытой линии.
  Пока работает веб-чат (клиент и его данные в CRM уже видны).
- **Открытая линия**: клиент получает два приветствия подряд — оставить одно в настройках линии.
- **RuStore**: 1.0.51 на модерации; тестовый аккаунт для модератора 79787973366 / Avtodrug2026.

## Следующее

   (плитка на главной обещает «Подберём по VIN или фото»).
2. **Замер задержки push**: время отправки в push, при получении — событие в AppMetrica с задержкой;

3. **Воронка в AppMetrica**: search → offers_open → add_to_cart → checkout_open → order_placed —
   смотреть через 1–2 недели после публикации, где бросают.
