2. **Сообщения без детали — 24%.** Разбор 72 случаев (11.10):

     (Febi, Sufix) в OEM-каталоге вообще не значатся — по ним метод ничего не доказывает, поэтому «нет» используем только
     для номера марки самой машины. Где применяется:
     1. **Номер клиента** («артикул X подойдёт?»): `FULLY` — «подтверждает каталог по VIN»; `NONAPPLICABLE` у номера марки —
        «в каталоге вашей машины его нет: не подходит или заменён»; `PARTIAL` (машина найдена по словам) — «возможно».

     Цена: один запрос на номер, кэш на диске. Не сделано: для аналогов других фирм нужны другие признаки (звёзды ≥5
     поставщиков остаются).

       артикул Toyota прислан для Audi.

     - `GetVehicleInfo` — подробности машины по ssd; дополнить машину, найденную по словам.
     - `GetCatalogInfo` — что умеет каталог: `vinsearch, wizardsearch2, quickgroups, detailapplicability, fulltextsearch`.

     - `FindVehicleByPlateNumber` (+ `IdentifyByPlateNumberFull`) — машина по госномеру: клиент, не знающий VIN, помнит
       номер. В движке госномер уже разбирается (`req.plate`); проверить, сколько клиентов так пишут.
     - `FindVehicleByFrame / FrameNo` — японские frame-номера (понимаем в `findVehicle`).
     - `ExecCustomOperation` — операции отдельных каталогов (DAF по номеру шасси): грузовики, нам не нужно.
     - `sysproperty filter_level`: `basic` — «обобщённая» машина (найдена по параметрам), `full` — расшифрована по VIN.
       Для машин по словам фильтрация деталей неточная — это уже сказано клиенту.
     Laximo.Search (`uss/…`, отдельный тариф) и Laximo.DOC (поиск по артикулу, нет доступа) — вне нашего тарифа.
   - **Вопросы клиенту, когда VIN каталог не знает (выложено 12.10):** просим марку, модель, год, объём двигателя
     и коробку (или фото СТС); просьба и VIN запоминаются, ответ клиента без VIN подхватывается. Мастер Laximo уточняется

11. **Помощники разработки — роли, не система агентов.** Опираемся на то, что у нас есть проверка: сценарии, эталон
    и замеры. Предложение помощника либо проходит их, либо отбрасывается.

      - номера только из Laximo и ABCP, сами не придумываем;
      - сторону проверяем по каталогу и по ценам;

      - ошибка каталога — `catalog_error`, а не падение;
      - модели — только текст без телефонов и VIN;
      - закупочные цены никуда не отдаём.

      Решает пользователь: он знает предмет («датчик импульсов» = коленвал), модель бывает неправа.
      Принятое — в правила, отклонённое запоминаем, чтобы не предлагать снова.
    - **Не заводим** отдельных «писателя тестов» и «разборщика функций»: тесты пишутся вместе с каждой правкой.
