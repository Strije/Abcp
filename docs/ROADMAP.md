# План работ — приложение «Автодруг» (обновлён 25.09.2026)

## Следующее

1. **Обучение**
   - Приветствие при первом запуске: 4 экрана с листанием и «Пропустить» — поиск в одном поле,
     фото VIN / упаковки, гараж и «Моя машина», уведомления и оплата. Последний экран объясняет,
     зачем уведомления, и только потом спрашивает разрешение Android.
   - Разовые подсказки на месте (пузырь у элемента при первом визите): 📷 в подборе, «потяните вниз»
     в заказах, ★ в гараже, «Фото упаковки» в поиске.
   - В профиле — «Как пользоваться» (показать приветствие ещё раз).
2. **Гарантия у избранных брендов** (панель ABCP «Избранные бренды»: срок + рейтинг). Значок 🛡 и ★ рейтинга —
   только у предложений со складов АвтоДруг (так написано на avtodrug92.ru/garantija), по нажатию — условия бренда
   со страницы гарантии; фильтр «С гарантией»; список — на сервере (обновляется без выпуска приложения).
3. **Звёздочки «достоверный аналог»**: сервер тратит лимит articles/info (10/сутки) на самые искомые артикулы
   и запоминает кроссы навсегда.
4. **Выдача как на сайте** — нужны скриншоты сайта и приложения по одному номеру.
5. **Вебхук Битрикс24 → push об ответе менеджера в чате.** Правильный путь — чат приложения как
   собственный канал открытой линии (коннектор `imconnector`): ответы операторов приходят событием
   на наш сервер → push клиенту. Нужен администратор Битрикс24 (локальное приложение, права imopenlines/imconnector).
